## 📄 Sobre mi Sitio Web

Mi sitio actúa como un *hub* centralizado de mi identidad digital. Lo he diseñado pensando en la eficiencia y la claridad, asegurándome de que cada sección aporte valor a quien lo visita.

### Mi Enfoque de Diseño

* **Mobile First:** He priorizado la experiencia en celulares, asegurándome de que el sitio se vea increíble en pantallas pequeñas antes de escalarlo a escritorio.
* **Accesibilidad (A11y):** Creo en una web para todos. Por eso, he programado herramientas manuales para controlar el tamaño del texto y el contraste directamente en la interfaz.
* **Semántica:** He escrito el código HTML5 respetando su estructura lógica para que sea amigable con los lectores de pantalla y los motores de búsqueda.

## 🚀 Lo que encontrarás aquí

* **Diseño 100% Responsive:** Mi sitio se adapta fluidamente a cualquier dispositivo.
* **Identidad Visual Propia:** He elegido una paleta de colores (Azul, Teal y Gris) y tipografías (Montserrat y Open Sans) que reflejan profesionalismo y modernidad.
* **Secciones Dinámicas:**
    * **Hero:** Mi presentación personal inmediata.
    * **Formación:** Mi línea de tiempo académica en la UTEM.
    * **Habilidades:** Una grilla donde separo mis competencias técnicas de las blandas.
    * **Proyectos:** Una galería con tarjetas interactivas ("Cards") de mis trabajos académicos más destacados.
* **Interactividad:** He implementado animaciones `Scroll Reveal` para que el contenido aparezca suavemente a medida que exploras la página.

## 🛠️ Mis Tecnologías

* **HTML5:** Para una estructura semántica robusta.
* **CSS3:**
    * Uso de variables (`:root`) para mantener la coherencia visual.
    * **Flexbox y Grid** para maquetar mis contenidos de forma flexible.
* **JavaScript (Vanilla ES6):**
    * Para la lógica de mi menú móvil.
    * Para darle vida al widget de accesibilidad.
    * Para controlar las animaciones de aparición al hacer scroll.

## 💻 Cómo visualizar mi trabajo localmente

Como mi sitio es estático, es muy fácil de ejecutar. No necesitas instalar nada complejo.

1.  **Clona mi repositorio:**
    ```bash
    git clone [https://github.com/iAlvaradoUtem/proyecto-marca-personal.git](https://github.com/iAlvaradoUtem/proyecto-marca-personal.git)
    ```

2.  **Verifica las imágenes:**
    Asegúrate de que la carpeta `img/` contenga las imágenes mencionadas arriba para que todo cargue visualmente bien.

3.  **Ejecuta:**
    Simplemente abre el archivo `index.html` en tu navegador favorito (Chrome, Firefox, etc.).
